# Aplikasi Data Barang

Aplikasi ini dibuat menggunakan PHP dan MySQL
untuk mengelola data barang.

## 1. Data Barang

Halaman ini menampilkan data barang yang tersimpan
di dalam database.

![Data Barang](screenshots/data-barang.png)

## 2. Tambah Barang

Halaman ini digunakan untuk menambahkan barang baru
dengan mengisi nama, kategori, harga jual, harga beli,
stok, dan file gambar.

![Tambah Barang](screenshots/tambah-barang.png)

## 3. Ubah Barang

Halaman ini digunakan untuk mengubah data barang
yang sudah tersimpan di database.

![Ubah Barang](screenshots/ubah-barang.png)

## Teknologi yang Digunakan

- PHP
- MySQL
- HTML
- XAMPP
